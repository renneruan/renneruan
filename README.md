### 🤖 BERTomelo

I am the creator of **BERTomelo**, an open-source Portuguese language encoder model based on the ModernBERT architecture.
- Developed both 1k and 8k context window versions to handle varying document lengths.
- Focused on enhancing performance for Portuguese-specific NLP tasks (featured at BRACIS 2026).
- [Check it out on Hugging Face](https://huggingface.co/renneruan/BERTomelo-ModernBERT-Base-1k)
